# Сократ — нейропереводчик

Офлайн-переводчик для macOS в стиле DeepL. Выделите текст в любом приложении, быстро нажмите **⌘C ⌘C**, и рядом с курсором появится окно с переводом.

- **~200 языков** модели [Meta NLLB-200](https://github.com/facebookresearch/fairseq/tree/nllb), любые направления. Поиск языка по названию, избранные языки (английский, русский, армянский, немецкий, французский, испанский, португальский) — наверху списка.
- **Полностью офлайн.** Модель (NLLB-200 1.3B, int8, движок [CTranslate2](https://github.com/OpenNMT/CTranslate2)) лежит внутри приложения, текст никуда не отправляется.
- **Ничего не нужно устанавливать:** Python и модель встроены в приложение.
- **Всегда наготове:** значок `Σ` в строке меню, автозапуск при входе в систему.

## Установка

1. Скачайте .dmg из раздела **Releases**: `Sokrat-arm64.dmg` для Mac на M1–M4 или `Sokrat-intel.dmg` для Mac на Intel.
2. Откройте .dmg и перетащите «Сократ» в «Программы».

### Первый запуск

Приложение не подписано платным сертификатом Apple, поэтому macOS один раз его заблокирует:

- **macOS 15 и новее:** откройте «Сократ» → появится предупреждение → «Системные настройки → Конфиденциальность и безопасность» → внизу «Всё равно открыть».
- **macOS 13–14:** правый клик по «Сократ» в «Программах» → «Открыть» → «Открыть».
- Если не помогло, выполните в Терминале: `xattr -cr /Applications/Сократ.app`

Затем macOS попросит доступ **«Универсальный доступ»**: включите «Сократ» в «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ». Без этого программа не видит нажатия ⌘C.

## Как пользоваться

| Действие | Как |
|---|---|
| Перевести выделенное | ⌘C ⌘C (два нажатия в пределах 0,5 с) |
| Выбрать язык | нажмите на название языка, начните вводить для поиска |
| Поменять языки местами | кнопка ⇄ |
| Исправить исходный текст | правьте в верхнем поле, перевод обновится сам |
| Скопировать перевод | кнопка «Копировать» или ⌘↩ |
| Закрыть окно | Esc |

Язык текста определяется автоматически (около 70 языков; остальные выберите вручную). Всё переводится на основной язык (по умолчанию русский), а текст на основном языке — на запасной (по умолчанию английский). Оба меняются в меню `Σ`.

## Сборка

Сборку делает GitHub Actions (`.github/workflows/build.yml`): 

1. на Linux модель NLLB-200 скачивается и конвертируется в CTranslate2 int8 (результат кешируется);
2. на macOS (Apple Silicon и Intel) собирается приложение, в него встраиваются автономный Python ([python-build-standalone](https://github.com/astral-sh/python-build-standalone)) и модель;
3. сервер перевода запускается прямо из собранного приложения и проверяется;
4. приложение упаковывается в .dmg; если номера из `VERSION` ещё нет среди релизов, создаётся релиз.

Новая версия: поменяйте номер в файле `VERSION` и отправьте изменения в `main` — релиз создастся сам.

```
app/Sources/             приложение на Swift: перехват ⌘C⌘C, окно, меню, запуск сервера
server/translate_server.py  локальный сервер перевода (127.0.0.1:8765)
scripts/                 конвертация модели, сборка Python, приложения и .dmg
```

Лог сервера: `~/Library/Logs/Sokrat/server.log`.
